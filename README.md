# 🎬 Netflix Data Analysis Using Python

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Netflix Movies and TV Shows using Python. The objective is to explore Netflix content, identify meaningful patterns, and understand different trends through data analysis and visualization.

## 🎯 Project Objectives

- Analyze Movies and TV Shows distribution.
- Identify the top 10 countries by Netflix content.
- Explore the most popular genres.
- Analyze content ratings.
- Understand content release year trends.
- Analyze yearly content added to Netflix.
- Study the duration of Netflix movies.

## 📂 Dataset

- **Dataset Name:** Netflix Movies and TV Shows
- **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **File Name:** `netflix_titles.csv`

The dataset contains information about Netflix titles, including title, director, cast, country, release year, rating, duration, genre, and description.

## 🛠️ Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🧹 Data Cleaning

The following data cleaning operations were performed:

- Checked and handled missing values.
- Identified and removed duplicate records.
- Converted date columns into datetime format.
- Extracted year and month from the date column.
- Prepared the dataset for analysis.

## 📊 Exploratory Data Analysis

The following analyses were performed:

1. Movies vs TV Shows Distribution
2. Top 10 Countries by Netflix Content
3. Top 10 Netflix Genres
4. Content Ratings Distribution
5. Netflix Content by Release Year
6. Netflix Content Added by Year
7. Movie Duration Analysis

1. Clone or download this repository.
2. Open `Netflix_Data_Analysis.ipynb` in [Google Colab](https://colab.research.google.com/).
3. Download `netflix_titles.csv` from the Kaggle dataset linked above.
4. Run the notebook's upload cell and select the CSV file.
5. Run the remaining cells to perform the analysis and generate visualizations.
